## 🛠️ 技术栈

- **纯前端**：原生 HTML + CSS + JavaScript，零框架、零依赖，单文件即可运行
- **Canvas 动画**：星尘背景、行星轨道、黑洞吸积盘、恒星演化、细胞分裂等全部用 `<canvas>` 手写
- **响应式**：适配桌面与移动端，暗色星空主题

## 🎨 画画 AI 点评（可选后端）

「画画」标签页的 AI 智能点评通过一个后端服务实现，接口地址在 `index.html` 顶部的配置中：

```js
window.ZHENYU_CONFIG = {
  apiUrl: "https://...trycloudflare.com"  // 后端服务地址
};
```

该后端基于 Cloudflare Tunnel 临时暴露，**可替换**为你自己的服务地址。若该服务未运行时，画画功能仍可正常绘制，仅 AI 点评不可用。

## 🚀 本地运行

无需任何构建，直接用静态服务器打开即可：

```bash
# 任选一种
python3 -m http.server 8000
# 或
npx serve .
```

然后浏览器访问 `http://localhost:8000`。
